# 06 Desenho de Notas

Neste capítulo, implementaremos a lógica de desenho do Note.

## Declarando

Declare o sprite da skin da nota:

::: code-group

```TypeScript
export const skin = defineSkin({
    sprites: {
        // ...
        note: SkinSpriteName.NoteHeadCyan,
    },
})
```

```JavaScript
export const skin = defineSkin({
    sprites: {
        // ...
        note: SkinSpriteName.NoteHeadCyan,
    },
})
```

:::

## Desenho

Semelhante ao modo de reprodução, desenhamos o sprite da nota no retorno de chamada `updateParallel` .

::: code-group

```TypeScript
export class Note extends Archetype {
    // ...

    updateParallel() {
        const y = Math.unlerp(this.visualTime.min, this.visualTime.max, time.scaled)

        const layout = Rect.one.mul(note.radius).scale(1, -1).translate(0, y)

        skin.sprites.note.draw(layout, [1, -this.targetTime], 1)
    }
}
```
