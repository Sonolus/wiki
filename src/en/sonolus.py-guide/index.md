# Introduction

A guide to engine development using [Sonolus.py](https://github.com/qwewqa/sonolus.py).

This guide covers:

- Engine development concepts.
- Setting up a development environment.
- Building a complete one-lane, tap-only rhythm game engine.

Work through [Play](play/01), [Watch](watch/01), [Preview](preview/01), and [Tutorial](tutorial/01) in order because
each section builds on the previous one.

The source code for the guide's engine is available on
[GitHub](https://github.com/qwewqa/wiki-sonolus.py-guide-code).
