# 07 Note Result

In this chapter, we will mark `WatchNote` as scored and report its target time.

## Scored Archetype

As in [Play chapter 14](../play/14), mark the note as scored with the
[`is_scored`](https://sonolus.py.qwewqa.xyz/reference/sonolus.script.archetype/#sonolus.script.archetype.WatchArchetype.is_scored)
class attribute. In `guide/watch/note.py`, add it directly below `name`:

```python
class WatchNote(WatchArchetype):
    name = archetype_names.NOTE
    is_scored = True
```

## Result

In the same file, add this assignment at the end of `preprocess`, after calculating `visual_time`:

```python
class WatchNote(WatchArchetype):
    # ...

    def preprocess(self):
        # ...

        self.result.target_time = self.target_time
```

The result target uses the note's level time, not its scaled lifetime position. Replay judgments and accuracy are added
in [chapter 10](./10).
