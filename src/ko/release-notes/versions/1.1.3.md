# 1.1.3

## 변경사항

- 플레이 모드에 빨리 감기를 추가했습니다.
- 배치 저장을 추가했습니다.
- 제출된 다시보기 자동 삭제를 추가했습니다.
- 엔진에 시간 측정을 추가했습니다.
- 맞춤형 서버와 모음집에 설명을 추가했습니다.
- 서버가 엔진을 업데이트 할 때 선택된 스킨/배경/효과음/입자  초기화를 추가했습니다.
- 맞춤 서버에 텍스트 현지화 기능을 추가했습니다.
- 배경에 스케일을 추가했습니다.
- 시청 모드 진행 바의 시간 표시를 다른 모드와 일치하도록 변경했습니다.
- UI/UX를 개선했습니다.
- 성능을 개선했습니다.
