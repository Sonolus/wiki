# 1.1.3

## Lista de cambios

- Se agregó la función de avance rápido al modo de juego.
- Se agregó la función de guardado masivo.
- Se agregó la eliminación automática de repeticiones enviadas.
- Se agregó una métrica de tiempo al motor.
- Se agregó una descripción al servidor y la colección personalizados.
- Se añadió el restablecimiento de la skin, el fondo, los efectos de sonido y las partículas seleccionados cuando el servidor actualiza el motor.
- Se agregó la función de localización de texto al servidor personalizado.
- Se añadió una escala al fondo.
- Cambios a la visualización del tiempo en la barra de progreso del modo espectador para que coincida con la de los demás modos.
- Se mejoró la interfaz y la experiencia de usuario.
- Se mejoró el rendimiento.
