# 1.1.3

## 変更点

- 再生モードに早送り機能を追加しました。
- 一括保存機能を追加しました。
- 投稿したリプレイを自動で削除する機能を追加しました。
- エンジンに時間計測機能を追加しました。
- カスタムサーバーとコレクションに説明を追加しました。
- サーバーがエンジンを更新した際に、選択したスキン/背景/効果音/パーティクルをリセットする機能を追加しました。
- カスタムサーバーにテキストのローカライズ機能を追加しました。
- 背景にスケール機能を追加しました。
- 閲覧モードでの進捗バーの時間表示を、他のモードと一致するように変更しました。
- UI/UXを改善しました。
- パフォーマンスを改善しました。
